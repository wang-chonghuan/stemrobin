## Decisions and rationale

- **默认英文，zh 仍是源语言**：`DEFAULT_LOCALE = 'en'`，`t()` 缺 en 键仍回落 zh。
  代价是新访客首屏只看到已翻译完成的课（英文 16/16 vs 中文 30/98）——人知情后仍要英文默认。
- **hero 标题的断行是排版决定，不是折行意外**：`<br>` 断在逗号处，但第二行实测需要
  642px，所以用**容器查询**盯 `.sr-hero-copy` 的实际栏宽（≥660px 才生效），而不是视口宽度——
  侧栏在不同断点开合，同一视口宽度对应的可用宽度并不一样。窄于此则丢掉断点自行平衡折行。
  副作用：`container-type: inline-size` 让该栏不再由内容决定宽度，在手机竖排（`align-items:
  flex-start`）下会塌陷，故在该断点 `align-self: stretch` 补回。
- **端口 3200 单一真源**：写在 `app/vite.config.ts`，`launch.json` 只 attach，
  删掉原来重复的 `main-dev-3200` 条目。
- **图标按用途分别定尺寸**：源图 1254² 里 mark 只占 910×534，先裁到 mark 自身边界再放到白色
  方画布上——44px 品牌方块 90%、favicon 94%（小尺寸要最多墨）、apple-touch 88%（留 iOS 圆角遮罩）。
  tab 图标按 16/32/64 精确出三份并带 `sizes`，避免浏览器把细长 mark 缩到 16px。
- **域名走灰 apex + Azure 托管证书**：apex 必须 DNS only 才能让 Azure 走 HTTP 校验签发证书；
  `www` 保持 proxied，重定向规则才会在 Cloudflare 边缘触发。
- **只删 mynatree 自己的证书**：`cae-easyapp-shared` 是共享环境，还挂着 houserobin / prodshape /
  whichtouse 的证书，不能连带清理。
- **下线只删记录不删 zone**：两个域的 Cloudflare zone 保留在账号里，随时可重新指向。
